# 스포츠인더 — 공공체육시설 정보 서비스

HTML + CSS + Vanilla JavaScript로 만든 반응형 공공체육시설 탐색 프로젝트입니다.

## 화면 구성 (6페이지)
1. `index.html` — 홈 / 통합 검색 / 주요 시설 유형
2. `facilities.html` — 전국 시설 검색 / 지역·시설유형·운동종목 필터
3. `programs.html` — 실제 공개 강습 프로그램 + 종목별 활동 안내
4. `stats.html` — 2021 공공체육시설 유형별·지역별 통계
5. `map.html` — 카카오맵 API 연결 화면
6. `detail.html` — 시설 상세정보

## 사용 데이터
- 문화체육관광부 「전국공공체육시설 현황」 2021년말 기준
- 프로젝트에 포함한 시설 레코드: 1,698건 (시설 유형별 대표 실제 레코드)
- 2021 전국 공공체육시설 총계: 33,729개소
- 실제 공개 수영 프로그램 데이터: 152건
  - 원주시 드림체육관
  - 안성시국민체육센터
  - 세종특별자치시시설관리공단 수영장

## 핵심 기능
- 한국어 / English / 日本語 / 中文 언어 모드
- 시설명·지역·종목 통합 검색
- 시도 / 시설유형 / 운동종목 필터
- 시설 상세 페이지
- 실제 공개 강습 프로그램 검색
- 시설 유형에 따른 가능한 활동 안내
- 2021 시설 유형 / 시도별 통계
- 카카오맵 API 키 전용 설정 폴더
- 공공데이터 API 확장 폴더
- 안내 / 오류 / 성공 토스트 메시지
- 모바일 햄버거 메뉴 + 반응형 레이아웃

## 데이터 구조
`js/data/facilities.js`
```js
window.PUBLIC_FACILITIES = [
  {
    id: "facility-00001",
    type: "축구장",
    province: "서울",
    city: "종로구",
    name: "종로구 한강다목적운동장",
    address: "...",
    manager: "...",
    activities: ["축구", "유소년 축구", "생활축구"]
  }
];
```

배열 안에 시설별 객체를 저장하고, 검색할 때 필요한 필드만 선택해 화면에 출력합니다.

## 실행
VS Code Live Server를 사용하거나:
```bash
py -m http.server 5500
```
브라우저에서 `http://localhost:5500`

## 카카오맵
`config/kakao-map/kakao.config.js`
```js
window.KAKAO_MAP_CONFIG = {
  javascriptKey: "실제_JavaScript_키"
};
```

## 사진 교체
`images/facilities/` 폴더에 실제 사진을 넣을 수 있습니다.

## 주의
시설 현황은 2021년말 기준이며, 강습 데이터는 각 공개파일의 기준일이 서로 다릅니다.
현재 운영 여부·요금·프로그램 접수상태는 실제 시설의 최신 안내를 확인해야 합니다.
