오늘할일 반응형 웹앱

[파일 구성]
- index.html : 화면 구조
- style.css  : 디자인 및 반응형 스타일
- script.js  : 할 일 CRUD, 검색, 캘린더, 통계, IndexedDB 저장
- manifest.webmanifest : 앱 설치 정보
- sw.js : 오프라인 캐시와 알림 클릭 처리
- icon-192.png / icon-512.png : 설치용 앱 아이콘

[1단계 기본 기능]
- 할 일 등록·조회·수정·삭제·완료·되돌리기
- 오늘·예정·캘린더·통계·설정 화면
- IndexedDB 로컬 저장 및 반응형 레이아웃

[2단계 추가 기능]
- 상태·우선순위·카테고리 필터
- 날짜·우선순위·등록일·이름 정렬
- 매일·매주·매월 반복 일정 자동 생성
- 지연된 일을 오늘 또는 내일로 빠르게 재계획
- JSON 백업 내보내기 및 불러오기

[3단계 추가 기능]
- 할 일별 정각·10분 전·30분 전·1시간 전 알림
- 브라우저 알림 권한 확인 및 테스트 알림
- 홈 화면 설치가 가능한 PWA 구성
- 최초 온라인 실행 후 앱 화면 오프라인 사용
- 네트워크 연결 상태 안내

[4단계 추가 기능]
- 2장 온보딩과 첫 사용자용 빈 상태
- 라이트·다크·시스템 테마
- 큰 글씨와 화면 움직임 축소 설정
- 월요일·일요일 주 시작 요일 설정
- 알림 제목 숨김 개인정보 옵션
- 최근 7일 완료 수와 연속 달성 통계
- JSON·CSV 데이터 내보내기
- 삭제 5초 되돌리기와 중복 저장 방지
- 250ms 검색 지연 처리와 시간 기준 지연 상태 개선
- 키보드 포커스, 건너뛰기 링크, 상태 레이블 보강

[5단계 추가 기능]
- 설정 화면의 브라우저·저장소·오프라인·네트워크 자가진단
- IndexedDB 할 일 데이터 무결성 검사
- 새 Service Worker가 준비됐을 때 업데이트 배너와 즉시 적용
- 할 일 작성·수정 중 닫기 또는 페이지 이탈 시 미저장 내용 보호
- 320px 모바일 입력창 자동 확대 방지와 터치·고대비·인쇄 호환성 보완
- 앱 버전·출시 상태 표시 및 오류 안내 보강
- qa-checklist.html 자동 점검 8종과 실제 기기 수동 체크리스트

[실행 방법]
1. 모든 파일을 같은 폴더에 둡니다.
2. VS Code에서 oneul-todo-app 폴더를 엽니다.
3. index.html을 Live Server로 실행합니다.
4. 설정 화면에서 알림 권한을 허용하거나 앱 설치를 선택합니다.
5. 출시 전에는 qa-checklist.html을 Live Server로 열어 자동·수동 점검을 진행합니다.

[반응형 구간]
- 모바일: 320px~767px
- 태블릿: 768px~1199px
- 데스크톱: 1200px 이상

[참고]
- 할 일 데이터는 현재 브라우저의 IndexedDB에 저장됩니다.
- 다른 기기나 브라우저와 자동으로 동기화되지는 않습니다.
- Service Worker와 PWA 설치는 file://가 아닌 localhost 또는 HTTPS에서 동작합니다.
- 알림은 앱이 실행 중일 때 30초 간격으로 확인합니다.
- 순수 HTML/CSS/JavaScript 버전이므로 브라우저를 완전히 종료한 상태의 서버 푸시 예약 알림은 지원하지 않습니다.
